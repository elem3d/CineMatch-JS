# CineMatch JS 🎬

## Sobre o projeto
O CineMatch JS é um simulador interativo de recomendação de streaming que roda direto no terminal. O sistema conversa com a pessoa usuária, coleta seu perfil (nome, idade e gêneros favoritos) e compara essas informações com um catálogo de filmes e séries.

O projeto foi desenvolvido para demonstrar de forma prática o funcionamento de um algoritmo de recomendação, exibindo:
- O percentual de compatibilidade com cada conteúdo do catálogo.
- A classificação de afinidade (Alta, Média ou Baixa).
- O conteúdo mais recomendado com base nas respostas.
- Uma sugestão de novos gêneros para explorar.
- Uma interface em formato de menu interativo.

## Objetivo
Praticar e demonstrar o domínio dos principais conceitos de JavaScript abordados no Módulo 01 do curso de ReactNative do SENAI, incluindo:
- Lógica de programação e manipulação de tipos de dados.
- Estruturas de condição (if/else, switch/case) e repetição (do/while).
- Funções e Arrow Functions.
- Métodos de Array (map, filter, reduce, find, every, some).
- Programação Orientada a Objetos (Classes, Herança e this).
- Funções avançadas (Callbacks, Closures, Promises e Async/Await).
- Entrada de dados via terminal usando a biblioteca `prompt-sync`.

## Como executar o projeto

Para rodar o CineMatch JS no seu computador, você só precisa do Node.js instalado. Siga o passo a passo abaixo:

1. Clone este repositório ou baixe os arquivos na sua máquina.
2. Abra o terminal na pasta do projeto.
3. Instale a biblioteca de interação digitando o comando:
   ```bash
   npm install prompt-sync
